# Proyecto-final-ma-on

El proyecto debe estar estructurado con una arquitectura moderna que incluya los siguientes componentes. En primer lugar, debe contar con un frontend, que será la interfaz de usuario, y un backend, encargado de la lógica del sistema y la gestión de datos. La comunicación entre ambos debe realizarse mediante una API.

Para el desarrollo del frontend, los estudiantes pueden apoyarse en herramientas de diseño como Bootstrap, lo que permitirá crear interfaces responsivas y visualmente organizadas de manera más eficiente.
Para el despliegue, se utilizará la plataforma Render, donde estarán alojados tanto el frontend como el backend en servidores independientes, permitiendo una mejor organización y escalabilidad del sistema.
La base de datos será relacional, específicamente MySQL, y estará gestionada a través de Aiven, garantizando disponibilidad y seguridad en el manejo de la información.
El control de versiones del proyecto debe realizarse utilizando Git, mientras que el repositorio remoto estará en GitHub. Este repositorio deberá estar conectado con Render para implementar un proceso de despliegue automático (CI/CD), de manera que cada cambio realizado en el código se refleje automáticamente en la aplicación desplegada.
Para la entrega final del proyecto, cada estudiante o equipo deberá compartir:

El enlace del repositorio en GitHub, el cual debe contener todo el código fuente organizado, documentado y actualizado.
El enlace de la aplicación web desplegada en Render, funcionando correctamente y accesible en línea.
Además, es obligatorio que el repositorio incluya un archivo README bien estructurado, en el que se detalle:

La descripción del proyecto.
Las instrucciones para descargar o clonar el repositorio.
Los pasos necesarios para ejecutar el proyecto en un entorno local.
